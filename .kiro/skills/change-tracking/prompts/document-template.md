# 变更记录文档模板

## 使用说明

此模板用于生成变更记录文档。根据实际收集的信息填充各章节，部分章节可根据变更类型选择性显示。

---

## 模板内容

```markdown
# {变更标题}

## 元信息

| 属性 | 值 |
|------|-----|
| ID | {uuid} |
| 创建时间 | {YYYY-MM-DD HH:mm:ss} |
| 完成时间 | {YYYY-MM-DD HH:mm:ss} |
| 分支 | {branch_name 或 "分支信息不可用"} |
| Commit | {commit_hash 或 commit_range 或 "Commit 信息不可用"} |
| 类型 | {change_type} |
| 严重程度 | {severity，仅 Bug 修复时显示此行} |
| 标签 | {tags，逗号分隔} |

## 变更概要

{一句话描述本次变更的目的和主要内容}

## 详细描述

{详细说明本次变更的背景、目的和实现方式}

## 修改文件列表

| 文件路径 | 状态 | 改动行数 |
|---------|------|---------|
| {file_path_1} | {added/modified/deleted/renamed} | +{additions}/-{deletions} |
| {file_path_2} | {status} | +{additions}/-{deletions} |

## 具体改动

### {file_path_1}

#### 改动 1
- **位置**: {行号范围或函数名，如 L25-L30 或 function validateUser()}
- **改动**: {具体做了什么修改}
- **原因**: {为什么要做这个修改}

#### 改动 2
- **位置**: {位置}
- **改动**: {改动内容}
- **原因**: {修改原因}

### {file_path_2}

#### 改动 1
- **位置**: {位置}
- **改动**: {改动内容}
- **原因**: {修改原因}

## 根因分析

> 此章节仅在 Bug 修复时显示

### 问题症状

{描述问题的外在表现，用户看到了什么异常现象}

### 根本原因

{深入分析问题产生的根本原因，代码层面的问题是什么}

## 踩坑记录

> 如果开发过程中未遇到特殊问题，显示"无"

### 阻塞问题

{如果遇到阻塞性问题，记录问题和解决方案}

- **问题**: {问题描述}
- **解决方案**: {如何解决的}

### 误判记录

{如果发生错误的问题定位或判断}

- **误判内容**: {最初错误判断是什么}
- **原因分析**: {为什么会产生这个误判}

### 误改记录

{如果发生错误的修改尝试}

- **误改操作**: {做了什么错误的修改}
- **原因分析**: {为什么会做出这个错误修改}

## 影响分析

> 如果经严格检查后确认无外部影响，显示"无外部影响"

### 接口变更

{如果涉及接口契约改变，详细描述}

**变更前：**
```
{原接口定义或调用方式}
```

**变更后：**
```
{新接口定义或调用方式}
```

**影响说明**: {这个变更对调用方的影响}

### 数据结构变更

{如果涉及数据结构改变，描述前后差异}

**变更前：**
```
{原数据结构}
```

**变更后：**
```
{新数据结构}
```

**迁移说明**: {是否需要数据迁移，如何迁移}

### 受影响模块

{列出可能受此变更影响的其他模块}

- {模块1}: {影响说明}
- {模块2}: {影响说明}

## 代码差异

### 关键代码变更

> 只记录核心逻辑、接口变更、关键算法的代码差异

#### {file_path} (L{start_line}-L{end_line})

**修改前：**
```{language}
{before_code}
```

**修改后：**
```{language}
{after_code}
```

**说明**: {这段代码为什么要这样改}

### 批量变更摘要

> 大量同类改动使用摘要描述

- 重命名了 {n} 个文件：{简要说明}
- 格式化了 {n} 个文件
- 更新了 {n} 处导入语句

### 完整差异

查看完整 diff: `git diff {commit_hash}^..{commit_hash}`

或访问: {commit_link}
```

---

## 章节显示规则

| 章节 | 显示条件 |
|------|---------|
| 元信息 | 始终显示 |
| 变更概要 | 始终显示 |
| 详细描述 | 始终显示 |
| 修改文件列表 | 始终显示 |
| 具体改动 | 始终显示 |
| 根因分析 | 仅 Bug 修复时显示 |
| 踩坑记录 | 有内容时显示，否则显示"无" |
| 影响分析 | 有外部影响时详细显示，否则显示"无外部影响" |
| 代码差异 | 有关键代码变更时显示 |

## 文件名格式

```
YYYY-MM-DD_HHmmss_简短描述.md
```

示例：
- `2024-03-15_143022_修复登录验证.md`
- `2024-03-15_160530_添加用户权限模块.md`
- `2024-03-16_091245_优化查询性能.md`

**简短描述提取规则：**
- 从变更概要中提取 2-4 个中文词
- 或 3-5 个英文单词
- 去除特殊字符
- 用下划线连接
