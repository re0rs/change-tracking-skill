# DocumentGenerator - 文档生成器

## 职责

负责将收集的变更信息转换为结构化的 Markdown 文档。

## 生成流程

### 1. 确定变更类型

根据以下特征判断变更类型：

| 变更类型 | 判断依据 |
|---------|---------|
| Bug修复 | 修复、fix、bug、问题、错误、异常等关键词 |
| 新功能 | 新增、添加、实现、feature、新功能等关键词 |
| 重构 | 重构、refactor、优化结构、重新组织等关键词 |
| 性能优化 | 性能、优化、加速、performance、提升等关键词 |
| 配置变更 | 配置、config、环境、设置等关键词 |
| 文档更新 | 文档、readme、注释、docs等关键词 |
| 依赖升级 | 升级、更新、依赖、版本、package等关键词 |

### 2. 智能推荐标签

根据以下规则推荐标签：

**文件路径分析：**
- 包含 `api/`、`controller/`、`route/` → `API`
- 包含 `database/`、`model/`、`schema/` → `数据库`
- 包含 `cache/`、`redis/` → `缓存`
- 包含 `auth/`、`security/`、`permission/` → `安全`
- 包含 `ui/`、`component/`、`view/` → `UI`
- 包含 `test/`、`spec/` → `测试`
- 包含 `config/`、`setting/` → `配置`

**内容分析：**
- 涉及异步操作 → `异步`
- 涉及错误处理 → `错误处理`
- 涉及日志 → `日志`
- 涉及性能 → `性能`
- 涉及网络请求 → `网络`

### 3. 评估 Bug 严重程度

仅当变更类型为"Bug修复"时评估：

| 严重程度 | 判断依据 |
|---------|---------|
| high | 系统崩溃、数据丢失、安全漏洞、阻塞核心功能 |
| medium | 功能异常但可绕过、影响用户体验、非关键错误 |
| low | 界面显示问题、小错误、边缘情况 |

### 4. 提取简短描述

从变更概要中提取简短描述用于文件名：

**规则：**
1. 移除标点符号
2. 提取关键动词+名词组合
3. 中文：2-4 个词
4. 英文：3-5 个单词
5. 用下划线连接

**示例：**
- "修复用户登录时密码验证失败的问题" → "修复登录密码验证"
- "Add user authentication module" → "add_user_auth"

### 5. 生成文件名

格式：`YYYY-MM-DD_HHmmss_简短描述.md`

```javascript
// 示例代码逻辑
const now = new Date();
const timestamp = now.toISOString()
  .replace(/[-:]/g, '')
  .replace('T', '_')
  .substring(0, 15);
const fileName = `${timestamp}_${shortDescription}.md`;
```

### 6. 填充文档模板

按照 `document-template.md` 中的模板结构填充内容：

1. **元信息区域**
   - 生成 UUID
   - 记录时间戳
   - 填充 Git 信息
   - 填充变更类型、严重程度、标签

2. **变更概要和详细描述**
   - 简洁的一句话概要
   - 详细的背景和实现说明

3. **修改文件列表**
   - 列出所有修改的文件
   - 标注状态（新增/修改/删除/重命名）

4. **具体改动**
   - 每个文件的每处改动
   - 包含位置、改动内容、修改原因

5. **根因分析**（仅 Bug 修复）
   - 问题症状
   - 根本原因

6. **踩坑记录**
   - 阻塞问题及解决方案
   - 误判记录及原因
   - 误改记录及原因

7. **影响分析**
   - 接口变更
   - 数据结构变更
   - 受影响模块

8. **代码差异**
   - 关键代码变更
   - 批量变更摘要
   - commit 链接

## 输出格式

生成完整的 Markdown 文档内容，可直接写入文件。

## 示例输出

```markdown
# 修复用户登录验证失败的问题

## 元信息

| 属性 | 值 |
|------|-----|
| ID | a1b2c3d4-e5f6-7890-abcd-ef1234567890 |
| 创建时间 | 2024-03-15 14:30:22 |
| 完成时间 | 2024-03-15 14:35:18 |
| 分支 | fix/login-validation |
| Commit | a1b2c3d |
| 类型 | Bug修复 |
| 严重程度 | high |
| 标签 | 安全, 用户认证 |

## 变更概要

修复用户登录时因密码哈希比较逻辑错误导致验证失败的问题。

## 详细描述

用户反馈无法正常登录系统，经排查发现是密码验证函数中使用了错误的比较方法...

（后续章节略）
```

## 注意事项

1. **信息不可用时的处理**
   - Git 信息不可用：显示"信息不可用"，不影响其他内容
   - 某章节无内容：显示"无"或省略章节

2. **代码差异精简**
   - 只记录关键代码（核心逻辑、接口、算法）
   - 大量同类改动用摘要
   - 提供 commit 链接供查看完整 diff

3. **格式规范**
   - 使用标准 Markdown 语法
   - 代码块标注语言
   - 表格对齐整洁
